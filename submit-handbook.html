Band Key · 提交上架操作手册

本手册覆盖「本地构建 → 签名 → 上传 → 后台提交」全流程。红色提醒处为容易出错、需你亲手检查的地方。

一、构建前检查（已完成）

✅ 已配置：显示名 Band Key · 版本 1.0.0 · 图标双端 · cap sync 通过
✅ 出口加密合规：iOS Info.plist ITSAppUsesNonExemptEncryption=false
✅ 隐私标签：数据不收集

二、iOS 本地构建与签名

  1. 注册 Bundle ID（首次）：在 developer.apple.com → Identifiers 注册 com.chordbuddy.app。
  2. 打开工程：
    cd "/Users/jiayilin/Library/Application Support/TRAE SOLO CN/ModularData/ai-agent/work-mode-projects/6aa2eb69515f6463df1f30df/chordbuddy-app"
npx cap open ios
  3. 配置签名：Xcode → 选中 App target → Signing & Capabilities → 勾选 Automatically manage signing → 选择你的 Team（付费开发者账号）。Bundle Identifier 应为 com.chordbuddy.app。
  4. 选真机/iPad 目标（不要 Simulator）→ Product → Archive。
  5. Distribute：Distribute App → App Store Connect → Upload。文件会自动上传，也可在 Organizer 导出 .ipa 后用 Transporter 提交。
⚠️ 首次构建若提示需要访问 GitHub 拉取 SPM 依赖（Capacitor 插件），请确保网络可用且取消代理对 github.com 的屏蔽；此类进程会因网络被断而失败。
⚠️ 签名省略：Profiles/Certificates 由 Xcode 自动管理，无需手动；但必须已登录你的付费开发者账号并选择 Team。

三、Android 本地构建与签名

3.1 生成 / 持有发布密钥（只做一次，务必妥善保管，丢失无法换签）

keytool -genkeypair -v \
  -keystore bandkey-release.keystore \
  -alias bandkey \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -storepass 你的强密码 -keypass 你的强密码 \
  -dname "CN=Band Key, OU=Dev, O=YourName, L=City, S=State, C=CN"
⚠️ keystore 与密码属于你账号的私密凭据，请自行生成并妥善保存，勿提交到 git/公开仓库。我无法替你保管。

3.2 配置 signingConfig（在你确认 keystore 后填入）

# android/app/build.gradle（示意：把 app 内 grading 引到 keystore 路径）
android {
  signingConfigs {
    release {
      storeFile file("../bandkey-release.keystore")
      storePassword "你的强密码"
      keyAlias "bandkey"
      keyPassword "你的强密码"
    }
  }
  buildTypes { release { signingConfig signingConfigs.release } }
}

3.3 构建 Release AAB（Play 要求 AAB）

cd android
./gradlew bundleRelease
# 产物: android/app/build/outputs/bundle/release/app-release.aab

四、后台提交流程

App Store Connect

  1. 新建 App → 平台 iOS → 名称/主语言/包 ID（选 com.chordbuddy.app）/Bundle ID 匹配。
  2. 填「App Store 信息」：描述/关键词/截图/隐私政策 URL（用 privacy-policy.html 部署后的 URL）。
  3. 「定价」→ 选择定价档次（免费或制定价格）。
  4. 「App 隐私」→ 隐私政策 URL + 数据收集声明（不收集）。
  5. 提交审核（App Review）；等待 1-3 天，被拒后按理由修改重提。

Google Play Console

  1. Play Console → 创建应用 → 填写信息、国家/地区、上传 app-release.aab。
  2. 数据安全表单 → 不收集任何数据；目标受众 → 全年龄。
  3. 内容分级问卷 → 全年龄 / E。
  4. 正式发布：推送内部/封闭测试，再提升到生产。
  5. 需 $25 一次性注册费（Play Console 开发者账号）。

五、常见审核风险自查

  • iOS 需真实可访问的「支持 URL」与「隐私政策 URL」——请用你自己的网站/GitHub Pages 托管。
  • 截图尺寸必须是官方要求（iOS 6.7″/6.5″/5.5″/iPad；Android 各分辨率），否则提交会报尺寸错误。
  • 若未来加内购/广告/账号，需同步更新隐私声明并开启相应权限。
  • 首次 iOS 发布会走「出口合规」问询：选「使用豁免（出口合规豁免）」即可，因为本应用无加密传输/内容。
