  • iOS App Store Connect：新建 App（Bundle ID 匹配）→ 填写名称/副标题/描述/关键词/截图/隐私政策 URL → 设置定价与可用性（免费或定价）→ 提交 "可供销售" → 等待审核（1-3 天）。营销/支持 URL 需可访问。
  • Android Google Play：Play Console 新建应用 → 填应用信息与向用户声明数据（本应用不收集数据）→ 上传 AAB → 内容评级 → 目标受众 → 提交正式发布。

⚠️ 首次上架前：在 App Store Connect 需填 iTunes 出口合规证明 与 隐私政策 URL。若你还没有可访问的公司/个人网站，可先用一个临时静态托管页面（如 GitHub Pages）承载隐私政策。
